# 🤖 Jarvis - Text-Based Virtual Assistant in C

A simple **text-based virtual assistant** built using the **C programming language**. This is my **first GitHub project**, created before I even started college as part of my journey to improve my programming skills.

## ✨ Features

- 🕒 Displays the current system time
- 🌐 Opens Google
- 📺 Opens YouTube
- 🎵 Plays a song on YouTube
- 💬 Opens ChatGPT
- 📝 Opens Notepad
- 👋 Exit command to close the assistant

## 🛠️ Technologies Used

- C Programming
- Standard C Libraries
  - `stdio.h`
  - `stdlib.h`
  - `string.h`
  - `time.h`

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/your-repository-name.git
```

2. Open the project in VS Code or any C IDE.

3. Compile the program

Using GCC:

```bash
gcc Jarvis.c -o Jarvis
```

4. Run the executable

```bash
./Jarvis
```

> **Windows Users:** If you're using MinGW, run:

```bash
Jarvis.exe
```

## 💻 Available Commands

| Command | Action |
|---------|--------|
| `time` | Shows current time |
| `google` | Opens Google |
| `youtube` | Opens YouTube |
| `song` | Plays a YouTube song |
| `chatgpt` | Opens ChatGPT |
| `notepad` | Opens Windows Notepad |
| `exit` | Closes Jarvis |

## 📸 Example

```
Jarvis: Hello !!! I am Jarvis

You: time
Current Time: Sat Jun 28 20:15:44 2026

You: google
Jarvis: Opening Google

You: exit
Jarvis: GoodBye !!! Have a nice day :)
```
