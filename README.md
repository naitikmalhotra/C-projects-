# 🤖 Jarvis - Text-Based Virtual Assistant in C

A simple **text-based virtual assistant** built using the **C programming language**.

This is my **first programming project** and my **first GitHub repository**, built **before I even started college**. I created this project to practice core C concepts and understand how real-world console applications are structured.

---

## ✨ Features

- 🕒 Display the current system time
- 🌐 Open Google
- 📺 Open YouTube
- 💻 Open GitHub
- 💬 Open ChatGPT
- 🎵 Play a song on YouTube
- 📝 Open Windows Notepad
- 👋 Exit the assistant

---

## 🛠️ Built With

- C Programming Language
- Standard C Libraries
  - `stdio.h`
  - `stdlib.h`
  - `string.h`
  - `time.h`

---

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/your-repository-name.git
```

### 2. Navigate to the project folder

```bash
cd your-repository-name
```

### 3. Compile the program

```bash
gcc Jarvis.c -o Jarvis
```

### 4. Run the program

**Windows**

```bash
Jarvis.exe
```

**Linux/macOS**

```bash
./Jarvis
```

> **Note:** The commands that open websites and Notepad use Windows' `system()` command, so those features currently work only on Windows.

---

## 💬 Available Commands

| Command | Description |
|---------|-------------|
| `time` | Shows the current system time |
| `google` | Opens Google |
| `youtube` | Opens YouTube |
| `github` | Opens GitHub |
| `chatgpt` | Opens ChatGPT |
| `song` | Plays a YouTube song |
| `notepad` | Opens Windows Notepad |
| `exit` | Closes Jarvis |
